# Обновление статистики игроков 2016 г.р.

Проект использует только Node-скрипт `update_fhm_2016_stats.mjs`.
Источник данных на странице: `all_2016_players_season5.js`.

## Что делает скрипт

- Берет команды только из целевых турниров/групп:
  - турнир `51` (формат 4х4): `Группа Б`, `Группа В`;
  - турнир `48` (формат 5х5): `Группа А`.
- Получает составы команд и статистику игроков.
- Формирует поля: игрок, группа, команда, игры, голы.
- Сортирует: голы (убывание), игры (убывание), имя (возрастание).
- Перезаписывает `all_2016_players_season5.js`.

## Защита и валидация

- Проверяются значения аргументов (`--seasonId`, `--delayMs`, `--outputJs`).
- Путь `--outputJs` должен оставаться внутри рабочей директории.
- Перед записью данные проходят фильтрацию некорректных строк.
- Режим fail-safe: битые строки отбрасываются, но запись выполняется только если валидных данных достаточно.

## Быстрый запуск

Требуется Node.js 18+ (рекомендуется 20+).

```powershell
node .\update_fhm_2016_stats.mjs
```

Пример с параметрами:

```powershell
node .\update_fhm_2016_stats.mjs --seasonId 5 --delayMs 120 --outputJs all_2016_players_season5.js
```

## Что проверять после запуска

1. В консоли есть:
   - количество обработанных команд;
   - количество итоговых строк игроков;
   - путь к JS-файлу.
2. Обновляется `all_2016_players_season5.js`.
3. После перезагрузки `index.html` таблица показывает новые данные.

## Если API временно недоступен

- Повторите запуск через 1–2 минуты.
- Увеличьте паузу между командами:

```powershell
node .\update_fhm_2016_stats.mjs --delayMs 250
```
